# Hand-written Baseline Profile for the launcher's hot startup and interaction paths.
#
# This is NOT a measured profile: it was written without a device, using wildcard rules
# that cover every method of the classes involved in
#   - cold start of the home screen         (Application, HomeActivity, UIObject,
#                                            LauncherGestureActivity, WidgetContainerView)
#   - swipe gesture detection               (TouchGestureDetector and its nested classes)
#   - opening the app drawer, search, scroll (AppListActivity, AbstractListActivity,
#                                            ListFragmentApps, AppsRecyclerAdapter, AppFilter)
# Flags: H = hot, S = startup, P = post-startup, L = class is loaded at startup.
# It can later be replaced by a profile generated with a macrobenchmark generator test.
